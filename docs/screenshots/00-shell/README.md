# Bằng chứng giao diện shell

Chụp các ảnh sau khi frontend và backend có dữ liệu demo:

1. `dashboard-desktop.png` — Bảng tổng quan ở chiều rộng desktop (tối thiểu 1280 px), gồm sidebar, topbar, tiêu đề trang và thẻ thống kê.
2. `inventory-desktop.png` — Báo cáo tồn kho với bảng dữ liệu và badge trạng thái tồn.
3. `inventory-tablet.png` — Báo cáo tồn kho ở chiều rộng khoảng 768 px để kiểm tra shell và bảng không vỡ bố cục.
4. `api-error-banner.png` — Dashboard hoặc Tồn kho khi backend không khả dụng, hiển thị thông báo lỗi tiếng Việt.

Không có ảnh PNG giả lập trong thư mục này. Chỉ bổ sung ảnh sau khi chụp từ ứng dụng đang chạy.
