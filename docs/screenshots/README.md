## Hướng dẫn chụp

1. Chạy frontend ở `http://localhost:5173`
2. Độ phân giải **1920×1080**, zoom browser 100%
3. Dùng seed data có tên lô/mẻ dễ hiểu (DEMO-001)
4. **Che** mật khẩu / IP nội bộ nếu nhạy cảm
5. Lưu PNG, đặt tên theo bảng trên

### Windows

- `Win + Shift + S` — vùng chọn
- Hoặc Snipping Tool
