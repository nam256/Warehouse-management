# M4 — QR Batch Passport + Recall Simulator

Thư mục lưu bằng chứng giao diện cho Gate M4.

Ảnh cần chụp khi demo:

1. Hộ chiếu lô hiển thị vật tư, chất lượng, CCP, lệnh sản xuất và QR.
2. Kết quả mô phỏng thu hồi nhiều tầng với thời gian chạy.
3. File CSV UTF-8 mở đúng tiếng Việt.

Mô phỏng là thao tác chỉ đọc, không thay đổi tồn kho hoặc trạng thái chất lượng.
