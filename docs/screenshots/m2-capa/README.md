# Bằng chứng giao diện M2 — CAPA/NCR

Thư mục này dành cho ảnh chụp màn hình `/capa` khi chạy dữ liệu demo.

## Checklist chụp ảnh

- Tab **Đang mở** hiển thị nguồn sai lệch, trạng thái, hạn xử lý, nguyên nhân và hành động.
- Tab **Quá hạn** hiển thị badge đỏ.
- Tab **Đã đóng** hiển thị disposition và thông tin xác minh.
- Dashboard hiển thị badge số CAPA quá hạn.
- Ảnh chụp ở desktop tối thiểu 1280 px; không chứa token hoặc dữ liệu nhạy cảm.

Chưa tuyên bố bằng chứng UAT cho đến khi ảnh được chụp từ phiên chạy thật.
